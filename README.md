## ◈ ABOUT THE PROJECT

**Vishnu Portfolio** is my personal developer portfolio, created to establish a professional digital presence and showcase my journey in technology, development, and creative problem-solving.

Rather than being just another static portfolio, this project focuses on presenting personal information and development work through an engaging web experience, combining modern frontend technologies with interactive design elements.

It serves as a central place to explore my profile, discover my work, understand my technical interests, and connect with me.

## ✨ HIGHLIGHTS

- **Personal Branding** — A dedicated digital identity and professional online presence.
- **Interactive Experience** — Motion-driven interface elements for a more engaging experience.
- **Modern UI** — A contemporary visual approach with carefully designed layouts.
- **Project Showcase** — A dedicated space to present development work and projects.
- **Responsive Design** — Designed to provide an accessible browsing experience across screen sizes.
- **Contact & Connectivity** — A digital touchpoint for professional communication.

## 🚀 GETTING STARTED

Want to explore the project locally? Follow these steps.

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/Guruvishnu444/vishnu-04.git
```

### 2. Navigate to the project

```bash
cd vishnu-04
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in your browser

Visit the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```

## 📦 BUILD FOR PRODUCTION

To generate an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

The production-ready files will be generated inside the `dist` directory.
